# 10 源工作簿核验与适配说明

## 1. 当前资料状态

原始《AI组件测试对象清单》工作簿当前未包含在仓库可见文件中。本文件没有读取到它，因此不声称知道其 sheet 名、表头、样例值、宏、公式或实际数据。任何工作簿字段解释、映射规则和导入数量都必须等取得副本后通过实际核验补充。

本文件的作用是给后续核验和适配建立安全流程，不是虚构源 Excel 分析结果。

## 2. 取得工作簿后的核验清单

在建立导入适配器前，应获得经授权的脱敏样例，并记录：

1. 文件名、格式版本、大小、SHA-256、取得日期和提供人/来源。
2. 文件类型（XLSX/XLS/CSV/其他）、是否加密、是否含 VBA、是否有外链。
3. 所有 Sheet 的名称、可见性、行数列数、标题行位置、合并单元格区域。
4. 每个 Sheet 的列名、数据类型分布、空值率、重复值、示例值（脱敏）。
5. 公式单元格和缓存值情况；确认是否必须保留显示值，以及读取库是否能读到缓存结果。
6. 是否存在隐藏行列、筛选、数据验证、命名区域、超链接、嵌入对象或批注。
7. API 类型、服务名称、目标环境、方法、地址、认证方式、请求样例和业务校验列是否分散在多个 Sheet。
8. 图片/文档附件是嵌在工作簿、独立文件还是仅有路径；确认合法授权和实际文件可用性。
9. 是否包含 Token、密码、内网地址、个人信息或生产数据；未经脱敏不得进入通用测试夹具。
10. 工作簿由人维护还是由其他系统生成；是否存在多个版本及向后兼容需要。

扫描阶段只读工作簿，不执行宏、不刷新外部链接、不运行公式、不访问 URL。

|---|---|---|---|---|---|---|---|

此表目前是空白模板；不能据此推断实际字段。

## 4. 适配原则

- 原始工作簿视为导入源，不直接作为运行时数据库。
- 导入时先预览结构，再由用户确认 Sheet、标题行、字段映射和目标环境。
- 导入草稿与正式保存分离；错误报告指出 sheet/行/列并允许修正。
- 不隐式把列名相似视为语义相同；需显式映射或经过审批的版本化规则。
- 密钥、密码等疑似秘密列默认遮蔽并映射为秘密引用，不能导入到普通文本配置。
- 公式不执行；若来源依赖公式结果，需用非执行方式读取已缓存值并明确提示可信性，或要求源系统导出静态值。
- 超链接/附件引用不自动打开或下载；只按已批准的导入根目录处理本地附件。
- 保留源文件哈希、导入时间、映射版本、错误和警告摘要，以便复现。
- 只导入用户选择的记录；不得自动把工作簿内所有目标都变成可执行压测任务。

## 5. 映射到 AI-PERF 模型的候选方向

以下只是待工作簿核验的候选映射，不表示源文件含有对应列：

| 规范概念 | 候选目的模型 | 需要核对 |
|---|---|---|
| 组件/API 名称和说明 | `API_PROFILE` / `REQUEST_SPEC` 的展示元数据 | 是否一行一接口、是否有版本/环境区分 |
| 服务地址、方法和请求样例 | `REQUEST_SPEC` | 地址是否模板化、是否包含真实秘密 |
| 请求参数或变量 | `REQUEST_SPEC` 与 `DATASET` | 固定配置还是逐用例变量 |
| 文件类型/路径 | `FILE_ASSET` 引用 | 文件是否实际随表提供、路径相对哪个根目录 |
| 成功预期/响应字段 | `VALIDATION_RULE` | 是否能转换为安全、确定的规则表达式 |
| 测试场景或步骤描述 | 多步 `REQUEST_SPEC` 草稿 | 是否包含执行顺序和前后依赖 |

无法稳定映射或有歧义的字段进入人工审核，不推测含义。

## 6. Excel 文件处理约束

- 仅读取支持的 OOXML 工作簿；若需要旧 `.xls`，必须单独评估离线依赖和安全性。
- 不启用 VBA、外部链接刷新、Power Query 或嵌入对象。
- 对 ZIP 容器展开大小、Sheet 数、行列数和单元格字符串长度做上限保护。
- 对公式单元格明确是否读公式文本或缓存值；不计算公式。
- 不信任扩展名；检查文件签名、结构和解析器错误。
- 对重复/空标题生成可定位的导入错误，不静默覆盖列。
- 日期、百分比、科学计数、前导零和时区按明确规则转换，保留必要的原始值用于审计。

## 7. 后续补充工作

取得脱敏原件后应：

1. 只读统计所有 sheet、行列和字段特征，不输出真实凭据或个人信息。
2. 与业务方核对每列语义、必填性、单位、枚举和目标授权方式。
3. 填充字段字典和映射表，明确转换规则与拒绝条件。
4. 建立最小化脱敏测试夹具，并保留原件 SHA-256，不把原件加入代码仓库。
5. 对映射结果逐行计数和抽样核对；导入错误可下载但需脱敏。
6. 将工作簿版本、适配器版本和字段映射版本纳入数据集来源元信息。

## 8. 待确认

1. 原始工作簿的实际文件、版本、所有者及使用授权。
2. 是否允许提供脱敏样例；是否有不可出域字段。
3. 工作簿是否是唯一数据源，还是只作组件/API 元数据清单。
4. 附件是否独立提供、路径规则及文件哈希是否已有。
5. 导入结果是创建 API/请求草稿、数据集，还是仅用于人工参考。
6. 工作簿更新频率、版本兼容、重复导入和变更审计规则。
